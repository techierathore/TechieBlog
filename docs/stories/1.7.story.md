### Architecture Patterns from Story 1.6

**Layout Structure (already implemented):**
```
.layout > .header + .main-wrapper (.main-content + .sidebar) + .footer
```
- Most pages use `.main-content` with sidebar
- Series page uses `.main-content--full` (no sidebar)

**IDisposable Pattern (CRITICAL):**
Components that subscribe to events MUST implement `IDisposable`:
```razor
@implements IDisposable

@code {
    protected override async Task OnInitializedAsync()
    {
        ThemeService.OnThemeChanged += HandleThemeChanged;
    }

    private void HandleThemeChanged(string theme, bool darkMode)
    {
        // Update local state
        InvokeAsync(StateHasChanged);
    }

    public void Dispose()
    {
        ThemeService.OnThemeChanged -= HandleThemeChanged;
    }
}
```

**Icons Namespace Alias:**
```razor
@using Icons = Microsoft.FluentUI.AspNetCore.Components.Icons

<FluentIcon Value="@(new Icons.Regular.Size20.Search())" />
```

**Fluent UI Button Patterns:**
```razor
<FluentButton Appearance="Appearance.Accent" OnClick="@HandleClick">Primary</FluentButton>
<FluentButton Appearance="Appearance.Outline">Secondary</FluentButton>
<FluentButton Appearance="Appearance.Stealth" IconStart="@(new Icons.Regular.Size20.Search())" />
```

### Placeholder Content Guidelines

Use clear placeholder text to indicate dynamic content:
- Post titles: `"[Post Title Placeholder]"` or actual sample text from mockups
- Author names: `"[Author Name]"` or sample names like "John Developer"
- Dates: Use actual dates from mockups (e.g., "Dec 15, 2025")
- Post counts: `"[X] posts"` or sample numbers
- Images: `<div class="placeholder-image">Image</div>`
- Content: `"[Post content will appear here]"`
