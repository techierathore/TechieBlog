# Story FIX-002: Wire Up Password Reset Flow

## Status

Done

## Story

**As a** registered user who has forgotten my password,
**I want** to reset my password using an email link,
**so that** I can regain access to my account.

## Acceptance Criteria

1. ResetPasswordPage.razor successfully resets passwords without throwing NotImplementedException
2. ForgotPasswordPage.razor sends reset emails via SendPasswordResetEmailAsync
3. Backend AuthSvc.ResetPassword() and RequestPasswordReset() are called with proper parameters
4. Reset token validation and expiration are properly handled
5. Password strength validation errors are surfaced to the user

## Tasks / Subtasks

- [ ] Task 1: Implement ResetPasswordAsync in AuthService.cs (AC: 1, 3, 4, 5)
  - [ ] Remove NotImplementedException from ResetPasswordAsync method
  - [ ] Extract reset token from SvcData (likely from JwToken or a custom field)
  - [ ] Extract new password from SvcData.LoginPass
  - [ ] Call objAuthSvc.ResetPassword(token, newPassword)
  - [ ] Return result.IsSuccess to indicate reset outcome
- [ ] Task 2: Implement SendPasswordResetEmailAsync in AuthService.cs (AC: 2, 3)
  - [ ] Remove NotImplementedException from SendPasswordResetEmailAsync method
  - [ ] Extract email from SvcData.LoginEmail
  - [ ] Call objAuthSvc.RequestPasswordReset(email, baseUrl) as async method
  - [ ] Return true on success (note: backend returns success even for non-existent emails for security)

## Dev Notes

### Technical Details from FIX-PLAN

**Problem:** `ForgotPasswordPage.razor` works partially, but `ResetPasswordPage.razor` calls broken methods. Backend `AuthSvc.ResetPassword()` and `RequestPasswordReset()` are fully implemented.

**File to Fix:**
- `source/TechieBlog/Services/AuthService.cs` (lines 82-90)

**Current Code (Broken):**
```csharp
public Task<bool> ResetPasswordAsync(SvcData user)
{
    throw new NotImplementedException();
}

public Task<bool> SendPasswordResetEmailAsync(SvcData user)
{
    throw new NotImplementedException();
}
```

**Fix Implementation:**
```csharp
public async Task<bool> ResetPasswordAsync(SvcData user)
{
    var result = objAuthSvc.ResetPassword(user.JwToken, user.LoginPass);
    return result.IsSuccess;
}

public async Task<bool> SendPasswordResetEmailAsync(SvcData user)
{
    var result = await objAuthSvc.RequestPasswordReset(user.LoginEmail);
    return result.IsSuccess;
}
```
