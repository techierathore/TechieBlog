# Story 7.1: Dark Mode Theme Fixes - Sidebar and Public Pages

## Status
Draft

## Story
**As a** blog visitor,
**I want** the dark mode to display consistently across all sidebar widgets and public pages,
**so that** I can comfortably browse the blog in dark mode without visual inconsistencies.

## Acceptance Criteria

1. **AC1:** FluentUI Card components in sidebar (Categories, Search, Tags, Subscribe) must inherit dark theme colors properly
2. **AC2:** Category list items display readable text with proper dark mode colors
3. **AC3:** Badge components (post counts) display with appropriate dark mode contrast
4. **AC4:** Popular tags cloud displays with proper dark mode background and text colors
5. **AC5:** Subscribe form (Stay Updated) maintains proper dark mode styling
6. **AC6:** Search box in sidebar has proper dark mode input styling
7. **AC7:** All text remains readable with sufficient contrast in dark mode

## Dev Notes

- `source/BlogUI/Components/Sidebar.razor` - Sidebar component using FluentUI

### FluentUI Dark Mode Integration
FluentUI Blazor components use their own design tokens. The issue is that custom CSS classes don't automatically inherit FluentUI's dark mode. Need to:
1. Target FluentUI components with `[data-theme="dark"]` selector
2. Override FluentUI design tokens or use CSS custom properties

### CSS Variables Used
```css
--color-surface: #161B22 (dark mode)
--color-background: #0D1117 (dark mode)
--color-border: #30363D (dark mode)
--color-neutral: #C9D1D9 (dark mode text)
--color-neutral-light: #8B949E (dark mode secondary text)
```
