## Dev Notes

### Problem Analysis

The `ManageService.cs` file at `source/TechieBlog/Services/ManageService.cs` is a complete stub - ALL 10 methods throw `NotImplementedException`:

```csharp
public class ManageService<TEntity> : IManageService<TEntity>
{
    public byte[] DownloadFile(string aRequestUri, long aId)
    {
        throw new NotImplementedException();
    }

    public List<TEntity> GetAllList(string aRequestUri)
    {
        throw new NotImplementedException();
    }

    public TEntity GetIntSingle(string aRequestUri, int aId)
    {

    }

    public List<TEntity> GetReport(string aRequestUri, ReportInput aObj)

    }

    public TEntity GetSingle(string aRequestUri, long aId)

    }

    public List<TEntity> GetSubsListByString(string aRequestUri, string aValue)
    {
        throw new NotImplementedException();
    }

    public TEntity Save(string aRequestUri, TEntity aObj)
    {
        throw new NotImplementedException();
    }

    public TEntity Update(string aRequestUri, TEntity aObj)
    {
        throw new NotImplementedException();
    }

    public bool UploadFile(string aRequestUri, TEntity aObj, Stream aFiles, string aFileName)
    {
        throw new NotImplementedException();
    }
}
```

### Analysis Hypothesis

Based on the method signatures (using `aRequestUri` parameters), this appears to be a **legacy HTTP client service** designed to call a REST API. Since the architecture was refactored from separate API + Blazor WASM to direct Blazor Server, this service is likely obsolete.

The BlogSvc API project was removed in Story 1.2, which would have been the target for these HTTP calls.

### Likely Outcome

This service is probably **not used** and can be safely deleted. The analysis task should confirm this.
