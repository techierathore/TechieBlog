### Current Query Analysis
The GetPostsByTag query looks correct:
```sql
SELECT p.PostID, p.Title, ... 
FROM BlogPost p
INNER JOIN PostTag pt ON p.PostID = pt.PostId
WHERE pt.TagId = @TagId
    AND p.Published = TRUE
    AND (p.IsDeleted = FALSE OR p.IsDeleted IS NULL)
```

### Potential Issues
1. **PostTag table empty:** No associations exist between posts and tags
2. **Posts not published:** Posts may exist but have `Published = FALSE`
3. **Case sensitivity:** PostgreSQL column names might have case issues

### Database Check
Run this query to verify PostTag data:
```sql
SELECT pt.PostId, pt.TagId, p.Title, t.TagName 
FROM PostTag pt
JOIN BlogPost p ON pt.PostId = p.PostID
JOIN Tag t ON pt.TagId = t.TagId
WHERE p.Published = TRUE;
```

### Fix Approach
1. First verify data exists in PostTag table
2. If empty, either:
   - Add seed data for PostTag
   - Ensure ManagePost.razor saves tag associations
3. If data exists but query fails, debug SQL
