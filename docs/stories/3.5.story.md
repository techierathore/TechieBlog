# Story 3.5: Draft and Preview Workflow

## Status

Completed

## Story

**As an** author,
**I want** to save drafts and preview before publishing,
**so that** I can refine content before it goes live.

## Acceptance Criteria

1. Posts have status: Draft, Published, Archived
2. Save as draft doesn't make post public
3. Preview draft shows full post rendering (accessible only to author/editors)
4. Publish action changes status and sets publish date
5. Unpublish returns post to draft status
6. Draft indicator visible in post list
7. Preview link shareable for editorial review (with token - optional for MVP)

### Previous Story Insights
From Story 3.1: BlogPost has Published boolean. From Story 3.2: Markdown editor will handle content editing.

### Existing Code Analysis

**BlogPost.cs** has:
- `Published` (boolean) - already supports draft/published
- `CreatedOn` - when post was first created
- `UpdatedOn` - last modification
- **Missing:** `PublishedOn` - when post was published

**BlogPostRepo.cs** Insert method:
```csharp
vParams.Add("@Published", aPost.Published);
```
Already supports setting Published flag.

**BlogsList.razor** currently shows all posts without status column.

### Database Schema Update

May need migration to add PublishedOn:
```sql
ALTER TABLE Post ADD COLUMN PublishedOn TIMESTAMP;
```

### Post Status Strategy

**Option A (Simple - Use existing Published boolean):**
- Published = false → Draft
- Published = true → Published
- Add separate IsArchived boolean if needed

**Option B (Explicit - Add Status enum):**
- Status = 'Draft' | 'Published' | 'Archived'
- More explicit but requires model changes

**Recommendation:** Use Option A for MVP (leverage existing Published field).

### Service Methods Pattern

```csharp
public class BlogSvc
{
    public void SaveDraft(BlogPost post)
    {
        post.Published = false;
        post.UpdatedOn = DateTime.UtcNow;

        if (post.PostID == 0)
            PostRepo.Insert(post);
        else
            PostRepo.Update(post);
    }

    public void PublishPost(BlogPost post)
    {
        post.Published = true;
        post.PublishedOn = DateTime.UtcNow;
        post.UpdatedOn = DateTime.UtcNow;

        if (post.PostID == 0)
            PostRepo.Insert(post);
        else
            PostRepo.Update(post);
    }

    public void UnpublishPost(long postId)
    {
        var post = PostRepo.GetSingle(postId);
        if (post != null)
        {
            post.Published = false;
            post.UpdatedOn = DateTime.UtcNow;
            PostRepo.Update(post);
        }
    }
}
```

### PreviewPost.razor Pattern

```razor
@page "/admin/preview/{PostId:long}"
@attribute [Authorize(Policy = "AuthorOrAbove")]
@layout AdminLayout

@if (isLoading)
{
    <FluentProgressRing />
}
else if (post == null)
{
    <FluentMessageBar Intent="MessageIntent.Error">
        Post not found
    </FluentMessageBar>
}
else
{
    <div class="preview-banner">
        <FluentIcon Value="@(new Icons.Regular.Size16.Eye())" />
        <span>PREVIEW MODE - This post is not published</span>
    </div>

    <div class="preview-actions">
        <FluentAnchor Href="@($"/ManagePost/{PostId}")" Appearance="Appearance.Outline">
            Edit
        </FluentAnchor>
        @if (!post.Published)
        {
            <FluentButton Appearance="Appearance.Accent" OnClick="@PublishAndRedirect">
                Publish Now
            </FluentButton>
        }
    </div>

    <article class="article">
        <header class="article__header">
            <h1 class="article__title">@post.Title</h1>
            <div class="article__meta">
                <span>@post.CreatedOn.ToString("MMMM dd, yyyy")</span>
                <span>@ReadingTimeCalculator.Calculate(post.PostContent)</span>
            </div>
        </header>
        <div class="article__content markdown-content">
            @((MarkupString)renderedContent)
        </div>
    </article>
}

@code {
    [Parameter]
    public long PostId { get; set; }

    @inject BlogSvc BlogService
    @inject MarkdownRenderer Renderer
    @inject NavigationManager Navigation

    private BlogPost post;
    private string renderedContent = string.Empty;
    private bool isLoading = true;

    protected override async Task OnInitializedAsync()
    {
        post = BlogService.GetSinglePost(PostId);
        if (post != null)
        {
            renderedContent = Renderer.ToHtml(post.PostContent);
        }
        isLoading = false;
    }

    private void PublishAndRedirect()
    {
        BlogService.PublishPost(post);
        Navigation.NavigateTo($"/post/{post.Slug}");
    }
}
```
