### Implementation Patterns

**GetIntSingle Pattern** (convert int to long and delegate):
```csharp
public override T GetIntSingle(int aSingleId)
{
    return GetSingle((long)aSingleId);
}
```

**InsertToGetId Pattern** (use RETURNING clause):
```csharp
public override long InsertToGetId(Entity entity)
{
    using var vConn = GetOpenConnection();
    const string sql = @"
        INSERT INTO tablename (col1, col2, ...)
        VALUES (@Val1, @Val2, ...)
        RETURNING id_column";
    return vConn.ExecuteScalar<long>(sql, new { ... });
}
```
