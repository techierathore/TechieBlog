# Story FIX-003: Wire Up Token Refresh

## Status

Done

## Story

**As a** logged-in user,
**I want** my authentication session to be refreshed automatically,
**so that** I don't get logged out unexpectedly during my session.

## Acceptance Criteria

1. RefreshTokenAsync returns a valid AppUser with new tokens when given valid refresh credentials
2. RefreshTokenAsync returns null when refresh token is invalid or expired
3. User session persists seamlessly without requiring re-login during normal usage

### Analysis of Existing Token Pattern

The AuthSvc uses a simple token model where:
1. Access token and refresh token are the same (line 107-108 in AuthSvc.cs):
   ```csharp
   vValidatedUser.AccessToken = sJwToken;
   vValidatedUser.RefreshToken = sJwToken;
   ```
2. Tokens are stored in `UserLogin` table with 2-day expiry
3. `GetUserByToken` validates and retrieves user by token

**Potential Fix Implementation:**
```csharp
public Task<AppUser> RefreshTokenAsync(RefreshRequest refreshRequest)
{
    try
    {
        // Use existing GetUserByToken mechanism since access/refresh tokens are same
        var tokenData = new SvcData { JwToken = refreshRequest.RefreshToken };
        var vSvcResponse = objAuthSvc.GetUserByToken(tokenData);

        if (vSvcResponse == null)
        {
            return Task.FromResult<AppUser>(null);
        }

        string sDecryptedUser = AppEncrypt.DecryptText(vSvcResponse.ComplexData);
        var vReturnUser = JsonSerializer.Deserialize<AppUser>(sDecryptedUser);
        return Task.FromResult(vReturnUser);
    }
    catch (Exception)
    {
        return Task.FromResult<AppUser>(null);
    }
}
```
