# Story 2.3: Password Reset Flow

## Story

**As a** registered user,
**I want** to reset my password via email,
**so that** I can regain account access if I forget my credentials.

2. Reset link generated with secure token
3. Token expires after 24 hours
4. Reset form validates new password strength
5. Password successfully changed via reset link
6. User redirected to login after successful reset
7. Invalid/expired tokens show appropriate error message

### Token Generation Pattern

```csharp
using System.Security.Cryptography;

public string GenerateSecureToken()
{
    var randomBytes = new byte[32];
    using var rng = RandomNumberGenerator.Create();
    rng.GetBytes(randomBytes);
    return Convert.ToBase64String(randomBytes)
        .Replace("+", "-")
        .Replace("/", "_")
        .Replace("=", "");
}
```

### AuthSvc Extension Pattern

```csharp
public class AuthSvc
{
    private readonly IPasswordResetTokenRepo TokenRepo;

    public Result<string> RequestPasswordReset(string email)
    {
        var user = UserRepo.GetUserByEmail(email);
        if (user == null)
        {
            // Don't reveal if email exists - return success anyway
            return Result<string>.Success(null);
        }

        var token = GenerateSecureToken();
        var resetToken = new PasswordResetToken
        {
            UserId = user.UserId,
            Token = token,
            CreatedAt = DateTime.UtcNow,
            ExpiresAt = DateTime.UtcNow.AddHours(24),
            IsUsed = false
        };

        TokenRepo.Insert(resetToken);

        // For dev, log the reset URL
        var resetUrl = $"/reset-password/{token}";
        AppLogger.LogInformation($"Password reset link: {resetUrl}");

        return Result<string>.Success(token);
    }

    public Result<bool> ResetPassword(string token, string newPassword)
    {
        var resetToken = TokenRepo.GetByToken(token);
        if (resetToken == null)
            return Result<bool>.Failure("Invalid reset link");

        if (resetToken.ExpiresAt < DateTime.UtcNow)
            return Result<bool>.Failure("Reset link has expired");

        if (resetToken.IsUsed)
            return Result<bool>.Failure("Reset link has already been used");

        // Validate password strength
        var passwordResult = PasswordValidator.Validate(newPassword);
        if (!passwordResult.IsValid)
            return Result<bool>.Failure(string.Join(". ", passwordResult.Errors));

        // Update user password
        var user = UserRepo.GetSingle(resetToken.UserId);
        if (user == null)
            return Result<bool>.Failure("User not found");

        user.LoginPass = AppEncrypt.CreateHash(newPassword);
        user.UpdatedOn = DateTime.UtcNow;
        UserRepo.Update(user);

        // Mark token as used
        TokenRepo.MarkUsed(resetToken.TokenId);

        return Result<bool>.Success(true);
    }
}
```

### ResetPasswordPage Implementation Pattern

```razor
@inject AuthSvc AuthService
@inject NavigationManager Navigation

protected override void OnInitialized()
{
    if (!string.IsNullOrEmpty(Token))
    {
        // Optionally validate token on load
        // For MVP, just validate on submit
    }
}

private async Task HandleSubmit()
{
    errorMessage = string.Empty;

    if (model.Password != model.ConfirmPassword)
    {
        errorMessage = "Passwords do not match";
        return;
    }

    var passwordResult = PasswordValidator.Validate(model.Password);
    if (!passwordResult.IsValid)
    {
        errorMessage = string.Join(". ", passwordResult.Errors);
        return;
    }

    var result = AuthService.ResetPassword(Token, model.Password);
    if (result.IsSuccess)
    {
        isSuccess = true;
        message = "Password reset successfully! Redirecting to login...";
        await Task.Delay(2000);
        Navigation.NavigateTo("/login?message=password-reset");
    }
    else
    {
        errorMessage = result.ErrorMessage;
    }
}
```
