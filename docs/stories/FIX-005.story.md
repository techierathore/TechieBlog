### BlogCommentRepo Stub Fixes

**GetIntSingle (line 70):**
```csharp
public override BlogComment GetIntSingle(int aSingleId)
{
    return GetSingle((long)aSingleId);
}
```

**InsertToGetId (line 117):**
```csharp
public override long InsertToGetId(BlogComment aComment)
{
    using var vConn = GetOpenConnection();
    const string sql = @"
        INSERT INTO blogcomment (postid, givenon, givenby, email, comment, published, parentcommentid)
        VALUES (@PostID, @GivenOn, @GivenBy, @Email, @Comment, @Published, @ParentCommentID)
        RETURNING commentid";
    return vConn.ExecuteScalar<long>(sql, new
    {
        aComment.PostID,
        aComment.GivenOn,
        aComment.GivenBy,
        aComment.Email,
        aComment.Comment,
        aComment.Published,
        aComment.ParentCommentID
    });
}
```

**Update (line 122):**
```csharp
public override void Update(BlogComment aComment)
{
    using var vConn = GetOpenConnection();
    const string sql = @"
        UPDATE blogcomment SET
            comment = @Comment,
            published = @Published
        WHERE commentid = @CommentID";
    vConn.Execute(sql, new
    {
        aComment.CommentID,
        aComment.Comment,
        aComment.Published
    });
}
```

### Database Schema
`BlogComment` table already exists with proper schema including:
- CommentID (PK)
- PostID (FK to BlogPost)
- GivenOn (timestamp)
- GivenBy (commenter name)
- Email
- Comment (text)
- Published (boolean - for moderation)
- ParentCommentID (nullable, for replies)

### Existing Working Methods
- GetAll() - returns all comments
- GetAllById(postId) - returns post comments with replies
- GetPostParentComments(postId) - parent comments only
- GetPostChildComments(postId) - reply comments only
- GetPagedData(pageSize, offset) - pagination
- GetPagedUnAppComments(pageSize, offset) - pending comments
- Insert(comment) - create new comment
- ApproveBlogComment(commentId) - approve comment
