# Story FIX-009: Tag Archive - Missing Category Name in PostCard

## Status

Done

## Story

**As a** blog reader,
**I want** to see the actual category name on post cards in the tag archive,
**so that** I can understand which category each post belongs to.

## Acceptance Criteria

1. CategorySvc injected into TagArchive.razor component
2. GetCategoryName() method retrieves actual category name from database
3. Post cards display correct category name instead of hardcoded "Blog"
4. Graceful handling when category is not found (fallback to "Uncategorized")
5. Build passes with no errors

## Dev Notes

### Problem Analysis

The `TagArchive.razor` file at `source/BlogUI/Pages/BlogPages/TagArchive.razor` has a hardcoded placeholder method (lines 180-184):

```csharp
private string GetCategoryName(BlogModels.BlogPost post)
{
    // Placeholder - would need CategorySvc to get actual name
    return "Blog";
}
```

This is called from the PostCard component (line 81):
```razor
<PostCard Category="@GetCategoryName(post)"
          Title="@post.Title"
          ...
```

### Implementation Pattern - Simple Approach

```csharp
@inject BlogEngine.Services.CategorySvc CategoryService

@code {
    private string GetCategoryName(BlogModels.BlogPost post)
    {
        if (post.CategoryId <= 0)
            return "Uncategorized";
            
        var category = CategoryService.GetSingle(post.CategoryId);
        return category?.CategoryName ?? "Uncategorized";
    }
}
```

### Implementation Pattern - Optimized with Caching

```csharp
@inject BlogEngine.Services.CategorySvc CategoryService

@code {
    private Dictionary<long, string> categoryCache = new();

    protected override async Task OnParametersSetAsync()
    {
        // Load all categories once for efficient lookup
        var allCategories = CategoryService.GetAllCategories();
        categoryCache = allCategories?.ToDictionary(c => c.CategoryId, c => c.CategoryName) 
                        ?? new Dictionary<long, string>();
        
        await LoadTag();
    }

    private string GetCategoryName(BlogModels.BlogPost post)
    {
        if (post.CategoryId <= 0)
            return "Uncategorized";
            
        return categoryCache.TryGetValue(post.CategoryId, out var name) 
            ? name 
            : "Uncategorized";
    }
}
```

### CategorySvc Reference

The `CategorySvc` has:
- `GetSingle(long id)` - Returns single BlogCategory by ID
- `GetAllCategories()` - Returns all categories
