### Settings Page Issue
The FluentCheckbox component has three checkboxes:
```razor
<FluentCheckbox @bind-Value="AllowComments" Label="Allow Comments" />
<FluentCheckbox @bind-Value="ModerateComments" Label="Moderate Comments Before Publishing" />
<FluentCheckbox @bind-Value="AllowRegistration" Label="Allow User Registration" />
```
The label text is invisible in dark mode.

### Series Dialog Issue
When clicking "Add New Series", a FluentDialog appears but doesn't inherit the dark theme:
```razor
<FluentDialog Hidden="false" Modal="true" TrapFocus="true">
```

### Fix Approach for FluentCheckbox
```css
[data-theme="dark"] fluent-checkbox::part(label) {
    color: var(--color-neutral);
}
```

### Fix Approach for FluentDialog
```css
[data-theme="dark"] fluent-dialog::part(control) {
    background-color: var(--color-surface);
    border-color: var(--color-border);
}

[data-theme="dark"] fluent-dialog-header {
    background-color: var(--color-surface-hover);
}
```
