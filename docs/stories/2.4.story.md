**I want** role-based access control enforced,

3. Authorization policies created for each permission level
4. [Authorize] attributes applied to protected pages/components
5. UI elements hidden based on user role
6. Unauthorized access redirects to login or shows 403 message
7. Role permissions documented in code comments

### Authorization Configuration Pattern

```csharp
// In Program.cs
builder.Services.AddAuthorizationCore(options =>
{
    options.AddPolicy("AdminOnly", policy =>
        policy.RequireRole("Admin"));

    options.AddPolicy("EditorOrAbove", policy =>
        policy.RequireRole("Admin", "Editor"));

    options.AddPolicy("AuthorOrAbove", policy =>
        policy.RequireRole("Admin", "Editor", "Author"));

    options.AddPolicy("ContributorOrAbove", policy =>
        policy.RequireRole("Admin", "Editor", "Author", "Contributor"));

    options.AddPolicy("Authenticated", policy =>
        policy.RequireAuthenticatedUser());
});
```

### App.razor Pattern with Authorization

```razor
<CascadingAuthenticationState>
    <Router AppAssembly="@typeof(App).Assembly">
        <Found Context="routeData">
            <AuthorizeRouteView RouteData="@routeData"
                                DefaultLayout="@typeof(MainLayout)">
                <NotAuthorized>
                    @if (context.User.Identity?.IsAuthenticated != true)
                    {
                        <RedirectToLogin />
                    }
                    else
                    {
                        <AccessDenied />
                    }
                </NotAuthorized>
            </AuthorizeRouteView>
        </Found>
        <NotFound>
            <PageTitle>Not Found</PageTitle>
            <LayoutView Layout="@typeof(MainLayout)">
                <p>Sorry, there's nothing at this address.</p>
            </LayoutView>
        </NotFound>
    </Router>
</CascadingAuthenticationState>
```

### AuthorizeView for Conditional UI

```razor
<!-- In AdminLayout.razor sidebar -->
<AuthorizeView Policy="AdminOnly">
    <Authorized>
        <FluentNavLink Href="/admin/tags">Tags</FluentNavLink>
        <FluentNavLink Href="/admin/users">Users</FluentNavLink>
    </Authorized>
</AuthorizeView>
```

### Page Authorization Attribute

```razor
@page "/admin/dashboard"
@attribute [Authorize(Policy = "EditorOrAbove")]
@layout AdminLayout

<!-- Page content -->
```
