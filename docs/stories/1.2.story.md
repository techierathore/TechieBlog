`source/TechieBlog/Program.cs` already uses direct service injection:

- `IUserLoginRepository` -> `UserLoginRepo`
- `IBlogUserRepo` -> `BlogUserRepo`
- `AuthSvc`

No changes to DI configuration are required for this story.
