# Story FIX-015: Sitemap.xml Generation (Epic 6, FR28)

## Status

Done

## Story

**As a** search engine crawler,
**I want** a valid sitemap.xml file at /sitemap.xml,
**so that** I can efficiently discover and index all blog content.

## Acceptance Criteria

1. Endpoint exists at `/sitemap.xml` returning valid XML sitemap
2. Sitemap includes all published blog posts with URLs and lastmod dates
3. Sitemap includes category archive pages
4. Sitemap includes tag archive pages
5. Sitemap includes static pages (home, about if exists)
6. XML format follows sitemap protocol specification
7. Sitemap auto-updates when content changes (no caching or reasonable cache duration)
8. robots.txt references sitemap location

### Sitemap XML Format

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://yourblog.com/</loc>
    <lastmod>2024-12-30</lastmod>
    <changefreq>daily</changefreq>
    <priority>1.0</priority>
  </url>
  <url>
    <loc>https://yourblog.com/post/my-first-post</loc>
    <lastmod>2024-12-28</lastmod>
    <changefreq>monthly</changefreq>
    <priority>0.8</priority>
  </url>
  <!-- More URLs... -->
</urlset>
```

### Service Implementation Pattern

```csharp
public class SitemapSvc
{
    private readonly IBlogPostRepo _postRepo;
    private readonly ICategoryRepo _categoryRepo;
    private readonly ITagRepo _tagRepo;
    private readonly string _baseUrl;
    
    public SitemapSvc(IBlogPostRepo postRepo, ICategoryRepo categoryRepo, 
                      ITagRepo tagRepo, IConfiguration config)
    {
        _postRepo = postRepo;
        _categoryRepo = categoryRepo;
        _tagRepo = tagRepo;
        _baseUrl = config["SiteSettings:BaseUrl"] ?? "https://localhost";
    }
    
    public string GenerateSitemap()
    {
        var sb = new StringBuilder();
        sb.AppendLine("<?xml version=\"1.0\" encoding=\"UTF-8\"?>");
        sb.AppendLine("<urlset xmlns=\"http://www.sitemaps.org/schemas/sitemap/0.9\">");
        
        // Home page
        AddUrl(sb, "/", DateTime.UtcNow, "daily", "1.0");
        
        // Published posts
        var posts = _postRepo.GetPublishedPosts(1000, 0);
        foreach (var post in posts)
        {
            var lastmod = post.UpdatedOn ?? post.CreatedOn;
            AddUrl(sb, $"/post/{post.Slug}", lastmod, "monthly", "0.8");
        }
        
        // Categories
        var categories = _categoryRepo.GetAll();
        foreach (var cat in categories)
        {
            AddUrl(sb, $"/category/{cat.Slug}", null, "weekly", "0.6");
        }
        
        // Tags
        var tags = _tagRepo.GetAll();
        foreach (var tag in tags)
        {
            AddUrl(sb, $"/tag/{tag.Slug}", null, "weekly", "0.5");
        }
        
        sb.AppendLine("</urlset>");
        return sb.ToString();
    }
    
    private void AddUrl(StringBuilder sb, string path, DateTime? lastmod, 
                        string changefreq, string priority)
    {
        sb.AppendLine("  <url>");
        sb.AppendLine($"    <loc>{_baseUrl}{path}</loc>");
        if (lastmod.HasValue)
            sb.AppendLine($"    <lastmod>{lastmod.Value:yyyy-MM-dd}</lastmod>");
        sb.AppendLine($"    <changefreq>{changefreq}</changefreq>");
        sb.AppendLine($"    <priority>{priority}</priority>");
        sb.AppendLine("  </url>");
    }
}
```

### Minimal API Endpoint

```csharp
// In Program.cs
app.MapGet("/sitemap.xml", (SitemapSvc sitemapSvc) =>
{
    var xml = sitemapSvc.GenerateSitemap();
    return Results.Content(xml, "application/xml");
});
```
