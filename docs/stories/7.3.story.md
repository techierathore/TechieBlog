# Story 7.3: Dark Mode Fix - About Page Connect With Us Section

## Status
Done

## Story
**As a** blog visitor,
**I want** the About page "Connect With Us" section to be readable in dark mode,
**so that** I can see and click on social media links.

## Acceptance Criteria

1. **AC1:** Social link button text is visible and readable in dark mode
2. **AC2:** FluentAnchor components with Appearance.Outline display properly
3. **AC3:** Icons in social links are visible
4. **AC4:** Hover states work correctly in dark mode

## Dev Notes

### Relevant Files
- `source/BlogUI/Pages/BlogPages/About.razor` - About page component

### Current Code
```razor
<FluentAnchor Href="https://github.com" Appearance="Appearance.Outline" Target="_blank">
    <FluentIcon Value="@(new Icons.Regular.Size20.Code())" Style="margin-right: 8px;" />
    GitHub
</FluentAnchor>
```

### Issue Analysis
The `Appearance.Outline` variant likely uses a light text color that becomes invisible on the dark background. Need to override FluentUI's default styling.

### Fix Approach
Add to theme CSS:
```css
[data-theme="dark"] fluent-anchor[appearance="outline"],
[data-theme="dark"] .fluent-anchor-outline {
    color: var(--color-neutral);
    border-color: var(--color-border);
}

[data-theme="dark"] fluent-anchor[appearance="outline"]:hover {
    color: var(--color-primary);
    border-color: var(--color-primary);
}
```
