# Story 7.7: Add Newsletter Management in Admin

## Status
Done

## Story
**As an** administrator,
**I want** to manage newsletter subscribers in the admin panel,
**so that** I can view, export, and manage my subscriber list.

## Acceptance Criteria

1. **AC1:** Admin menu includes "Subscribers" link
2. **AC2:** Subscribers list page displays all subscribers with email, date, status
3. **AC3:** Can filter subscribers by active/inactive status
4. **AC4:** Can search subscribers by email
5. **AC5:** Can toggle subscriber active status
6. **AC6:** Can export subscriber list to CSV
7. **AC7:** Displays total subscriber count

### CSV Export Implementation
```csharp
private async Task ExportToCsv()
{
    var subscribers = SubscriberService.GetSubscribersForExport();
    var csv = "Email,SubscribedOn,Status\n";
    foreach (var s in subscribers)
    {
        csv += $"{s.Email},{s.SubscribedOn:yyyy-MM-dd},{(s.IsActive ? "Active" : "Inactive")}\n";
    }
    // Use JS interop to download file
}
```
