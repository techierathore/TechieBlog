# Story 7.2: Dark Mode Fix - Search Page Alignment and Styling

## Status
Draft

## Story
**As a** blog visitor,
**I want** the search page to display correctly in dark mode with proper button alignment,
**so that** I can search for content without visual issues.

## Acceptance Criteria

1. **AC1:** Search button aligns vertically with the search text field
2. **AC2:** Search text field has proper dark mode styling (background, border, text color)
3. **AC3:** Search filters (category, date, sort) dropdowns display properly in dark mode
4. **AC4:** Search results cards maintain readability in dark mode
5. **AC5:** Search hint text is readable in dark mode

## Tasks / Subtasks

- [ ] Task 1: Fix search header form alignment (AC: 1)
  - [ ] Update `.search-header__form` flexbox alignment
  - [ ] Ensure FluentTextField and FluentButton have matching heights
  - [ ] Add `align-items: center` or `align-items: stretch` as needed

- [ ] Task 2: Style search text field for dark mode (AC: 2)
  - [ ] Add dark mode styles for FluentTextField in search context
  - [ ] Set proper background, border, and text colors

- [ ] Task 3: Fix search filter dropdowns (AC: 3)
  - [ ] Style FluentSelect components for dark mode
  - [ ] Ensure dropdown options are readable

- [ ] Task 4: Verify search results styling (AC: 4, 5)
  - [ ] Check `.search-result` card styling in dark mode
  - [ ] Fix `.search-hint` text color for dark mode

## Dev Notes

### Relevant Files
- `source/BlogUI/Pages/BlogPages/SearchResults.razor` - Search page component

### Current Issue
The search header form uses flexbox but doesn't have proper alignment:
```html
<div class="search-header__form">
    <FluentTextField ... Style="flex: 1;" />
    <FluentButton ...>Search</FluentButton>
</div>
```

### Fix Approach
Add CSS for `.search-header__form`:
```css
.search-header__form {
    display: flex;
    gap: var(--spacing-sm);
    align-items: stretch; /* or center */
}
```

### FluentUI Component Styling
FluentTextField and FluentButton have different default heights. Options:
1. Use `align-items: center` to vertically center both
2. Use `align-items: stretch` and ensure consistent heights
