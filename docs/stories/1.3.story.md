### MySQL to PostgreSQL Data Type Mapping

| MySQL Type | PostgreSQL Type | Notes |
|------------|-----------------|-------|
| `BIGINT AUTO_INCREMENT` | `BIGSERIAL` | Auto-incrementing 64-bit integer |
| `INT AUTO_INCREMENT` | `SERIAL` | Auto-incrementing 32-bit integer |
| `VARCHAR(n)` | `VARCHAR(n)` | Same syntax |
| `TEXT` | `TEXT` | Same syntax |
| `LONGTEXT` | `TEXT` | PostgreSQL TEXT has no length limit |
| `DATETIME` | `TIMESTAMP` | Use TIMESTAMP for datetime |
| `TINYINT(1)` | `BOOLEAN` | Convert to native boolean |
| `BIT(1)` | `BOOLEAN` | Convert to native boolean |
| `ENUM(...)` | `VARCHAR(50)` | Use VARCHAR with CHECK constraint or custom type |

### DbUp PostgreSQL Configuration
```csharp
var upgrader = DeployChanges.To
    .PostgresqlDatabase(connectionString)
    .WithScriptsFromFileSystem("PostgresScripts")
    .LogToConsole()
    .Build();
```

### GenericRepository Connection Update
The `BlogEngine/DaCore/` contains the base repository classes. The connection factory needs to use `NpgsqlConnection` instead of `MySqlConnection`.

```csharp
// Change from:
using var connection = new MySqlConnection(connectionString);
// To:
using var connection = new NpgsqlConnection(connectionString);
```

### File Naming and Coding Standards
- SQL script naming: Number prefix + PascalCase (e.g., `001-CreateTables.sql`)
- Table naming: PascalCase (e.g., `BlogUser`, `PostCategory`)
- Column naming: PascalCase (e.g., `UserId`, `CreatedOn`)
- Index naming: `Idx` prefix + PascalCase (e.g., `IdxPostSlug`)
- Foreign Key naming: `Fk` prefix + PascalCase (e.g., `FkPostUserId`)
- Primary Key naming: `Pk` prefix + PascalCase (e.g., `PkBlogPost`)
