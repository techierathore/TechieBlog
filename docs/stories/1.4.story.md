### Blazorise to Fluent UI Component Mapping

| Blazorise Component | Fluent UI Equivalent |
|---------------------|---------------------|
| `<Layout>` | `<FluentLayout>` |
| `<LayoutSider>` | `<FluentNavMenu>` (in sidebar pattern) |
| `<LayoutContent>` | `<FluentBodyContent>` |
| `<Bar>` | `<FluentNavMenu>` |
| `<BarItem>`, `<BarLink>` | `<FluentNavLink>` |
| `<BarDropdown>` | `<FluentNavGroup>` (expandable) |
| `<Dropdown>` | `<FluentMenu>` + `<FluentMenuButton>` |
| `<DropdownItem>` | `<FluentMenuItem>` |
| `<Button>` | `<FluentButton>` |
| `<Icon>` | `<FluentIcon>` |
| `<Container>` | `<div class="container">` or `<FluentStack>` |
| `<DataGrid>` | `<FluentDataGrid>` |
| `<Tabs>` | `<FluentTabs>` + `<FluentTab>` |
| `<Modal>` | `<FluentDialog>` |
| `<Alert>` | `<FluentMessageBar>` |

- `<BarDropdown>` / `<BarDropdownMenu>` / `<BarDropdownItem>` - Dropdown menus
- `<LayoutHeader>` / `<LayoutContent>` - Header and main content
- `<Dropdown>` / `<DropdownToggle>` / `<DropdownMenu>` - User menu
