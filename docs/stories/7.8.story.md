# Story 7.8: Theme Selector UI

## Status
Done

## Story
**As a** blog admin/user,
**I want** to select from 3 pre-built themes via a UI dropdown,
**so that** I can customize the blog's visual appearance.

## Background

The theme infrastructure already exists:
- `ThemeService.cs` defines 3 themes: fluent-modern, developer, minimal
- `ThemeProvider.razor` applies themes via data-site-theme attribute
- CSS files exist in `wwwroot/Themes/`: fluent-modern.css, developer-dark.css, minimal-clean.css
- Dark/Light mode toggle already works in Header

**What's missing:** A UI element to switch between the 3 themes.

## Acceptance Criteria

1. **AC1:** Theme dropdown/selector available in Settings page (admin)
2. **AC2:** Theme dropdown shows all 3 themes: Fluent Modern, Developer Dark, Minimal Clean
3. **AC3:** Selecting a theme applies it immediately (no page reload required)
4. **AC4:** Selected theme persists in LocalStorage
5. **AC5:** Theme selection survives browser refresh
6. **AC6:** (Optional) Theme preview/selector in Header for all users
7. **AC7:** Settings page theme section shows current theme and description

## Technical Notes

### Existing Infrastructure

```csharp
// ThemeService.cs already has:
public List<ThemeInfo> GetAvailableThemes() // Returns 3 themes
public async Task SetThemeAsync(string themeName) // Sets and persists theme
public async Task<string> GetCurrentThemeAsync() // Gets current theme
```

### Implementation Approach

1. **Settings.razor** - Add theme section:
```razor
@inject ThemeService ThemeService

<div class="settings-card">
    <h2>Theme</h2>
    <FluentSelect @bind-Value="selectedTheme"
                  @bind-Value:after="OnThemeChanged">
        @foreach (var theme in availableThemes)
        {
            <FluentOption Value="@theme.Id">@theme.Name</FluentOption>
        }
    </FluentSelect>
    <p class="theme-description">@GetThemeDescription()</p>
</div>
```

2. **Code-behind**:
```csharp
private List<ThemeInfo> availableThemes = new();
private string selectedTheme = "fluent-modern";

protected override async Task OnInitializedAsync()
{
    availableThemes = ThemeService.GetAvailableThemes();
    selectedTheme = await ThemeService.GetCurrentThemeAsync();
}

private async Task OnThemeChanged()
{
    await ThemeService.SetThemeAsync(selectedTheme);
}
```
