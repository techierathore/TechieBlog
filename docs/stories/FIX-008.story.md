# Story FIX-008: Category Archive - Dynamic Category Filter

## Status

Done

## Story

**As a** blog reader,
**I want** the search page category filter to show actual categories from the database,
**so that** I can filter search results by real categories instead of hardcoded options.

## Acceptance Criteria

1. CategorySvc injected into SearchResults.razor component
2. Category dropdown populated from CategorySvc.GetAllCategories() on initialization
3. Hardcoded category options removed from markup
4. Category filter applies correctly to search results
5. Build passes with no errors

## Dev Notes

### Problem Analysis

The `SearchResults.razor` file at `source/BlogUI/Pages/BlogPages/SearchResults.razor` has hardcoded category options (lines 31-36):

```razor
<FluentSelect TOption="string" @bind-Value="categoryFilter" Style="width: auto;">
    <FluentOption TOption="string" Value="">All Categories</FluentOption>
    <FluentOption TOption="string" Value="blazor">Blazor</FluentOption>
    <FluentOption TOption="string" Value="dotnet">.NET</FluentOption>
    <FluentOption TOption="string" Value="csharp">C#</FluentOption>
</FluentSelect>
```

### Implementation Pattern

```razor
@inject BlogEngine.Services.CategorySvc CategoryService

@* In the filters section *@
<FluentSelect TOption="string" @bind-Value="categoryFilter" Style="width: auto;">
    <FluentOption TOption="string" Value="">All Categories</FluentOption>
    @foreach (var cat in categories)
    {
        <FluentOption TOption="string" Value="@cat.Slug">@cat.CategoryName</FluentOption>
    }
</FluentSelect>

@code {
    private List<BlogCategory> categories = new();

    protected override void OnInitialized()
    {
        // Load categories
        categories = CategoryService.GetAllCategories()?.ToList() ?? new List<BlogCategory>();
        
        // Existing search initialization...
        if (!string.IsNullOrEmpty(Query))
        {
            searchQuery = Query;
            PerformSearch();
        }
    }
}
```

### CategorySvc Reference

The `CategorySvc` already has a `GetAllCategories()` method that returns `IEnumerable<BlogCategory>`.
