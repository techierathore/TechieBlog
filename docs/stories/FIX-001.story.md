# Story FIX-001: Wire Up User Registration

## Status

Done

## Story

**As a** new visitor,
**I want** to register for an account on the blog,
**so that** I can comment on posts and interact with the community.

## Acceptance Criteria

1. RegisterPage.razor successfully registers new users without throwing NotImplementedException
2. Backend AuthSvc.RegisterUser() is called with proper parameters (displayName, email, password)
3. Registration returns success/failure appropriately based on backend result
4. Error messages from backend validation (duplicate email, weak password) are surfaced to UI

## Tasks / Subtasks

- [ ] Task 1: Implement RegisterUserAsync in AuthService.cs (AC: 1, 2, 3)
  - [ ] Remove NotImplementedException from RegisterUserAsync method
  - [ ] Call objAuthSvc.RegisterUser() with proper parameter mapping
  - [ ] Map SvcData properties to RegisterUser parameters (FirstName as displayName, LoginEmail, LoginPass)
  - [ ] Return result.IsSuccess to indicate registration outcome
- [ ] Task 2: Handle registration errors (AC: 4)
  - [ ] Ensure Result<AppUser>.Failure messages propagate to UI
  - [ ] Test email already exists scenario
  - [ ] Test weak password scenario

## Dev Notes

### Technical Details from FIX-PLAN

**Problem:** `RegisterPage.razor` calls `AuthService.RegisterUserAsync()` which throws `NotImplementedException`, but backend `AuthSvc.RegisterUser()` is fully implemented.

**File to Fix:**
- `source/TechieBlog/Services/AuthService.cs` (lines 72-75)

**Current Code (Broken):**
```csharp
public Task<bool> RegisterUserAsync(SvcData user)
{
    throw new NotImplementedException();
}
```

**Fix Implementation:**
```csharp
public Task<bool> RegisterUserAsync(SvcData user)
{
    var result = objAuthSvc.RegisterUser(user.FirstName, user.LoginEmail, user.LoginPass);
    return Task.FromResult(result.IsSuccess);
}
```

### Backend Method Signature (Already Implemented)
Located at `source/BlogEngine/Services/AuthSvc.cs` line 182:
```csharp
public Result<AppUser> RegisterUser(string displayName, string email, string password)
```

The backend method handles:
- Input validation (displayName, email required)
- Password strength validation via PasswordValidator
- Email uniqueness check
- Name parsing (splits displayName into first/last)
- Password hashing
- User creation in database
