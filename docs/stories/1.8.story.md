1. Login page with email/password form, remember me checkbox, forgot password link
2. Registration page with display name, email, password, confirm password fields, and terms checkbox
3. Forgot password page with email input and instructions

5. All forms use Fluent UI form components (FluentTextField, FluentCheckbox, FluentButton)
6. Validation styling placeholders in place (error states, helper text)
7. Responsive design maintained (auth card centered, mobile-friendly)

### Fluent UI Form Component Mappings

| HTML Element | Fluent UI Component | Notes |
|--------------|---------------------|-------|
| `<input type="text">` | `<FluentTextField>` | Use `TextFieldType` for type |
| `<input type="email">` | `<FluentTextField TextFieldType="TextFieldType.Email">` | |
| `<input type="password">` | `<FluentTextField TextFieldType="TextFieldType.Password">` | |
| `<input type="checkbox">` | `<FluentCheckbox>` | |
| `<button type="submit">` | `<FluentButton Type="ButtonType.Submit" Appearance="Appearance.Accent">` | |
| `<a>` | `<a>` or `<FluentAnchor>` | Standard links for navigation |
