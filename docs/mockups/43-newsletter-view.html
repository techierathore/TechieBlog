Issue #24 — Shipping a MAUI admin app

Ravi Rathore · Sent Aug 1, 2026
Sent to 1,240 subscribers

This was the month the admin console stopped being a browser-only thing. I'd been carrying a laptop to conferences just to moderate comments over hotel wifi, so I gave the same Razor Class Library a second host — a MAUI Blazor Hybrid shell — and now the moderation queue lives one double-click away. It took a weekend, and about a third of that weekend was spent on two problems I'd cheerfully forgotten existed.

The RCL itself needed no changes. Every component in BlogUI already renders from injected services rather than reaching for HttpContext, which is the one discipline that makes a shared UI layer portable. What did need work was everything around the edges: configuration, the connection string, and the assumption — buried in three places — that there is always a circuit.

What actually broke

Two things. First, the desktop head has no reverse proxy in front of it, so anything that read forwarded headers to build absolute URLs produced links pointing at nothing. Second, PostgreSQL connections from a laptop that sleeps mid-query behave very differently from connections inside a datacentre — the retry policy that had never once fired in production fired constantly, and it turned out to be retrying the wrong class of error.

Both were cheap to fix once they were visible, which is the real argument for a second host: it exercises assumptions your server environment quietly satisfies for you. If you've been meaning to try MAUI Blazor Hybrid, do it against an app you already know well. The bugs it surfaces will be the interesting kind.
