Why migrate at all?

Fluent UI Blazor served us well, but TrBlazeUI's shadcn-style tokens give us dark mode for free and a far smaller CSS payload.

The plan

  1. Swap the app shell (FluentLayout → TbSidebar)
  2. Replace form controls page by page
  3. Delete the old theme provider
Rule of thumb: migrate leaf components first — shells last.
builder.Services.AddTrBlazeUI();

The rest of this post walks each component pair in detail.
