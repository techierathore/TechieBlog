Introduction

Microsoft Fluent UI provides a comprehensive set of components that follow modern design principles, making it an excellent choice for building professional Blazor applications.

Getting Started

First, you'll need to install the Microsoft.FluentUI.AspNetCore.Components NuGet package:

dotnet add package Microsoft.FluentUI.AspNetCore.Components

After installation, register the Fluent UI services in your Program.cs file:

builder.Services.AddFluentUIComponents();

Component Architecture

Fluent UI components are designed with accessibility in mind. They follow WAI-ARIA guidelines and provide proper keyboard navigation out of the box.
