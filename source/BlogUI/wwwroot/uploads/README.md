# Upload Directory Structure

This directory contains user-uploaded files organized by category.

| Category | Path | Max Size | Allowed Formats |
|----------|------|----------|-----------------|
| Profile Photos | /profiles/ | 2MB | jpg, png, webp |
| Company Logos | /logos/ | 500KB | jpg, png, svg, webp |
| Award Badges | /awards/ | 500KB | jpg, png, svg, webp |
| Skill Icons | /icons/ | 200KB | png, svg, webp |
| Blog Images | /blog/ | 5MB | jpg, png, gif, webp |
| CV Files | /cv/ | 10MB | pdf |
| General | /general/ | 5MB | jpg, png, gif, webp |

**Note:** Files are named using the pattern: `{category}_{userId}_{timestamp}_{guid}.{ext}`
